# S · 韩语学习工作台

一个可爱风格的韩语自学 Web 应用，包含音标、每日单词、语句跟读、对话练习、经典台词、养花精灵打卡等模块。

## 在线访问
https://123shao2613.github.io/S/

## 功能
- 40 个韩文字母音标学习（女声发音 + 口型图）
- 每日单词（按等级，收藏 / 复习 / 已学单词）
- 语句跟读（8 大场景，录音评分）
- 对话练习（8 个情境 + 自定义）
- 经典台词（韩剧双语字幕）
- 养花精灵每日打卡（成长 / 花蜜 / 心情）
- 学习数据仪表盘

## 技术
纯静态：HTML + CSS + 原生 JS，Web Speech API 韩文 TTS，localStorage 存储，PWA 可安装到手机主屏幕。
